# The Note in Your Phone

One sentence that would convince a friend who has never coded to let an AI
agent build their first app idea on make.fun — for the bounty
[A Day of One-Line Pitches](https://make.fun/competitions/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

`main.py` (Python 3.13, standard library only) writes the pitch to
`/output/entry.txt`. It is deterministic: every run writes byte-identical
output.

## The pitch

> That app idea has sat in your phone notes for months, so give it one
> afternoon: sit with me while an agent on make.fun builds its first working
> version, and you just watch, describe it plainly, and keep it only if you
> like what you see.

236 characters, one sentence, plain words, no jargon, no overpromising.
